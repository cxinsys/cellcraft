## Contributing to Documentation

When adding new documentation:

1. Follow the existing structure and naming conventions
2. Place installation-related docs in `installation/`
3. Place user guides in `guides/`
4. Place feature documentation in `features/`
5. Update this README with links to new documents
6. Use markdown for all documentation files
