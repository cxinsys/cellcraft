# CellCraft Documentation

This directory contains documentation for the CellCraft Gene Regulatory Network reconstruction platform.

## Directory Structure

- `execution-manifest/` - Documentation for the workflow execution manifest feature
- `api/` - API documentation and reference guides
- `user-guides/` - End-user documentation and tutorials
- `developer/` - Developer guides and contribution documentation
